## Overview

OBS Spout2 Config Manager streamlines the configuration of the OBS Spout2 plugin, which enables shared GPU texture streaming between applications on the same PC. It provides a GUI for setting Spout sender names, receiver source bindings, frame rate limits, and resolution parameters across multiple Spout streams without editing JSON config files.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **OBS Spout2 Config Manager** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Sender Config** | Configure Spout sender names and resolution for outgoing texture streams |
| **Receiver Binding** | Map Spout senders to OBS video sources with resolution matching |
| **Frame Rate Cap** | Set per-stream frame rate limits to manage GPU texture bandwidth |
| **Multi-Stream** | Manage multiple simultaneous Spout streams from one interface |
